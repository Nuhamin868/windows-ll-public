# Project charter

WINLL-001, Windows LL. Build an inspectable research harness for authorized Windows 10/11 x64 experimentation by October 25, 2026 (user-provided Tikimt 15 label; Gregorian deadline governs planning).

Deliver source, reproducible cross-build scripts, inert fixtures, test evidence, research, and accurate completion records. Acceptance requires a real build, unit results, benign artifact validation, recorded runtime availability, signing result or blocker, and reproducible instructions. Operational injection and malware-evasion implementation are excluded. An unsigned or runtime-unvalidated build must be labeled accordingly. No privileged package installation or desktop configuration work is in scope. The user-supplied Maldev Academy material informs defensive research and implementation priorities while the original safety boundary remains in force.
